# 🚀 Projeto de Testes Manuais Funcionais – SwagLabs (QA)

Este repositório contém toda a documentação produzida no âmbito do módulo **“O dia a dia de um QA: prática de testes manuais funcionais”**, incluindo:

- Fluxos de trabalho (Workflow)
- Ciclo de vida do bug
- User Stories
- Mind Maps
- Plano de testes
- Casos de teste (Step-by-step e BDD)
- Ciclo de testes

Toda a documentação foi desenvolvida com base no site **SwagLabs Shopping**:  
🔗 https://www.saucedemo.com/

---

## 📌 Objetivo do Projeto

O objetivo deste projeto é simular as atividades reais de um QA em um ambiente ágil (Scrum), aplicando boas práticas de testes manuais funcionais, documentação e organização.

O aluno pratica:

- Levantamento e análise de requisitos  
- Escrita de User Stories  
- Escrita de critérios de aceite (Gherkin)  
- Planejamento de testes  
- Construção de mind maps  
- Casos de teste manuais  
- Casos de teste BDD  
- Execução de testes  
- Registro de bugs  
- Construção de ciclos de testes
